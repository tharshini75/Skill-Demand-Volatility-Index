# Skill Demand Volatility Index

## Overview
This project analyzes job market trends and skill demand using Power BI. It helps identify the most in-demand skills and how their demand changes over time.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Dashboard Features
- KPI Cards
- Skill-wise Job Demand
- Year Filter
- Top Skills
- Skill Demand Trends

## Files Included
- Skill-Demand-Volatility-Index.pbix
- Skill-Demand-Volatility-Dashboard.pdf
- Dashboard.png

## Key Insights
- Identified the most demanded technical skills.
- Compared skill demand across different years.
- Visualized trends using interactive Power BI dashboards.
